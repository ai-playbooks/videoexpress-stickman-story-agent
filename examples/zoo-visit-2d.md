# Finn’s Day at the Zoo — 2D workflow

Reusable example for recreating a narrated zoo comedy in 16:9 flat 2D. This story keeps the name and narration from its 3D version; a new story should choose a fresh protagonist name. Follow [SYSTEM_PROMPT.md](../SYSTEM_PROMPT.md) for account verification, browser recovery, automatic production and mandatory tool policies.

The completed reference run contained 14 clips totaling 79.583338 seconds, approximately 1 minute 20 seconds. Its actual clips were about 5–6 seconds each; this is a measured example, not a claim that it met the usual 3–5 second narration target. For a requested one-minute version, shorten the lines before generating audio and measure the result. Do not speed up or cut speech to force a target.

## Production order

1. Use the selected signed-in VideoExpress browser session and a clean 16:9 project. Preserve the earlier version.
2. Generate, review and save a standalone 2D Finn master before any story frames. Use that same master in Reference Photo 1 throughout.
3. Plan every beat's incoming state, action and endpoint. Create one reviewed location reference for each recurring set, without Finn; use it in Reference Photo 2 at that location.
4. Set Image Type to 2D, Consistent Character ON, Narration Video ON, Creative mode OFF, image enhancement OFF, Advanced Mode OFF, Lipsync OFF and public sharing OFF.
5. Generate and inspect the starting image. Verify identity, interaction gaze, fixed layout, anatomy, prop state and space for movement before selecting it.
6. Enter only visual motion instructions. Click Create Video, then CloneVoice.ai → Category: System → Beau Whitaker New → scene narration → Import Speech. Preview the generated audio, then click Create Narration Video. Use the available verified labels if the UI changes.
7. Record the submitted job and inspect it before retrying. Review the completed clip and its actual endpoint before finalizing the next connected frame. Use endpoint observations in the prompt, not last-frame identity references.
8. Add each accepted clip once in order. Review joins, press Auto Align Clips on populated relevant tracks, save as **Finn’s Day at the Zoo — 2D**, verify save success and play through to the end. Retain the finished editor tab. Export only when requested.

## Master character

One full-body flat 2D cartoon stickman alone on a neutral cream studio background. Circular bald white head, expressive teal eyes and eyebrows, small orange nose, mustard yellow zip jacket, navy shorts, exactly two thin black arms with separate black hands, two thin black legs, white sneakers with teal soles. Relaxed three-quarter stance, both empty hands separated from torso, feet visible. Crisp stable ink contours, matte warm cel colors and simple drawn shadows. This master supplies identity; it does not dictate a lens-facing pose in story scenes.

Introduce the map, umbrella, handkerchief and animal encounters only in scene frames. Keep the face, costume and proportions tied to this original master. Generate matching 2D references rather than using the 3D run's images.

## Fixed set layouts

The camera stays on the SOUTH side of encounters, usually with Finn LEFT on the visitor path facing RIGHT and the animal RIGHT facing LEFT. Gaze follows the animal, not the lens. A cut to another habitat is motivated travel; consecutive beats within one habitat must carry the actual action state forward.

| Set | Fixed layout from the established camera |

| Entrance | Red-roof kiosk BACK LEFT; cream wall LEFT; green arch gate CENTER-RIGHT with the same silver tripod turnstile; sign and bench RIGHT; paved foreground path. Opening daylight becomes warm closing-time sunset. |
| Giraffe | Visitor path LEFT; low timber rail diagonally through CENTER; sandy habitat RIGHT; tall acacia BACK RIGHT; feeding platform FAR RIGHT; leaf rack RIGHT. |

## Source-frame correction example

The umbrella candidates initially showed an already-open canopy, skipping the next action; one also duplicated the umbrella. Repeated negative wording was ineffective. A simpler silhouette request produced a usable folded starting prop:

> One tightly folded cobalt-blue umbrella, shaped as a narrow pointed shaft, held horizontally across Finn's waist by both black hands. Empty sky above his head. Finn LEFT watches the peacock RIGHT; the peacock's green tail is already fully fanned. Keep the original garden landmarks.

During correction, use a simple starting-state motion description rather than retaining conflicting completed-action wording. After reviewing and selecting the corrected still, restore the full animation prompt: rotate that same umbrella upright, slide the runner, open one small blue canopy; the peacock reacts, closes its tail and departs. This is a prompting correction, not a guaranteed model behavior.

Keep damp jacket patches through later shots and describe crown droplets as clear blue water on a bald white head. Preserve umbrella ownership and hand contact; reject a cloth merged into a hand or an extra umbrella. The original master remains the face/anatomy authority even when preceding frames drift.

## Review limits

Auto Align closes timing gaps; it cannot fix spatial jumps, missing actions, duplicate animals, merged hands or face drift. The reference run's 79.58-second saved timeline and full playback were verified. Individual renders still need visual review: an instruction to walk away is not evidence of departure, and a correct still does not guarantee the animation preserves every detail. Correct failures within the authorized workflow and preserve successful earlier assets.

Keep per-run asset IDs, job URLs, account/session records and screenshots local. This example publishes the reusable production instructions and story, not private browser state.
