# Example request

```text
Topic: A struggling student discovers that small daily habits can transform his future.
Aspect ratio: 9:16
Target runtime: approximately 1 minute
```

Target runtime is optional; topic/story and aspect ratio are the two required inputs.

The agent should open or focus a visible supported browser first, honoring the user's selected session and recovering through available browser alternatives when necessary. After any explicitly requested account confirmation, create a connected story of short narration lines and continue routine production without per-clip approval requests. For this request, start with approximately 15 lines targeting 4 seconds each. Generate every line as a separate 3–5 second CloneVoice audio clip using Beau Whitaker, measure it, and create one matching silent 2D stickman video scene. Align each video to its own intact audio clip and assemble the pairs consecutively. Verify every pair’s start and end, then save the project without exporting it. Mandatory tool-policy requirements still apply.

Example opening beats (durations must be measured after generation):

Each row produces its own audio clip and video. Continue with connected beats through the story’s ending; these three rows are only an opening example.
