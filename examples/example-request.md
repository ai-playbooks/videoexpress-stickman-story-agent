# Example request

```text
I want you to create a narrated VideoExpress story about a struggling student who discovers that small daily habits can transform his future. Use my currently signed-in VideoExpress account and its included generation features. Make it 9:16, 2D stickman style, approximately one minute, and use the default Beau Whitaker narrator. You may generate and correct the required images, integrated narration, and videos; assemble, review, Auto Align, and save the project. Keep public-gallery sharing off. Do not purchase or upgrade anything, accept new terms, delete existing assets, change account-wide settings, switch providers, or publish publicly. Export the finished video only if I ask for an exported file.
```

The standard intake asks for story/topic, aspect ratio (Vertical 9:16 or Landscape 16:9 only), and narrator. It does not offer 1:1 or other ratios. Beau Whitaker is the narrator default, so production can continue with that voice when the user does not choose another.

The agent should open or focus a visible supported browser first, honoring the user's selected session and recovering through available browser alternatives when necessary. After any explicitly requested account confirmation, create a connected story of short narration lines and continue routine production without per-clip approval requests. For this request, start with approximately 15 lines targeting 3–5 seconds each. For every reviewed source image, create Beau Whitaker system-voice narration inside VideoExpress's integrated narration dialog, then generate the matching narrated 2D stickman clip. Inspect each finished clip, assemble the accepted clips consecutively, review every join, run Auto Align, measure the 55–65 second result, and save the project without exporting it.

Example opening beats (durations must be measured after generation):

| Scene | One-line narration | Matching video action |
| --- | --- | --- |
| 01 | Every morning, Milo stared at his unfinished homework. | Milo looks down at an open homework notebook. |
| 02 | Today, he decided to finish just one small task. | Milo picks up his pencil and starts one problem. |
| 03 | One tiny checkmark gave him a reason to smile. | Milo marks the completed problem and smiles. |

Each row produces one integrated narrated video clip. Continue with connected beats through the story’s ending; these three rows are only an opening example.
